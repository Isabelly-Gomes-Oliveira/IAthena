## Descrição ✏️
O projeto consiste em uma aplicação denominada "***IAthena***" que possui um agente de I.A. capaz de **averiguar a veracidade de informações contidas em vídeos e posts de redes sociais**, isto é, identificar *fake news* sem que o usuário tenha que pesquisar por conta própria. Todas as **fontes de pesquisa** são exibidas quando o usuário clica sobre o ícone que sobrepõe os apps permitidos. Ademais, dentro do aplicativo existe a opção de **personalizar o  ícone**, para tornar o app mais amplo para todos os públicos, pois saber a verdade é um direito de todos!
